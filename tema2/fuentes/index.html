01

TEORÍA ESENCIAL

Una dirección tiene varias partes

La URL es la dirección completa. El host es el nombre del servidor al que se dirige la conexión. Puede incluir subdominios, como www o campus.

EJEMPLO DIDÁCTICO · NO ES UN ENLACE

https://Esquemarevista.exampleHost:443Puerto/articuloRuta?tema=redesParámetro

Localiza el host

En estas direcciones, mira después de // y antes de la siguiente /. Si no hay ruta, termina antes de ?, # o al final.

Separa los extras

Si aparece usuario@, el host empieza después de @. El puerto, como :443, no forma parte del nombre del servidor.

No te dejes distraer

El nombre de otra web en la ruta o en un parámetro no cambia el host. Lee el nombre completo, no solo la primera palabra que reconozcas.

HTTPS protege la conexión

Una conexión HTTPS validada cifra el intercambio de datos y permite al navegador autenticar el sitio mediante su certificado. No garantiza que el contenido sea honrado.

Privado no significa anónimo

Al cerrar todas las ventanas privadas, el navegador no conserva el historial de esa sesión, pero pueden permanecer las descargas y los marcadores. Las webs y la red del centro pueden observar actividad.

Observa, sin cambiar nada.

No introduzcas contraseñas ni datos personales en las páginas consultadas. No cambies permisos o ajustes del centro, no abras modo privado y no borres el historial. Si un acceso está bloqueado, utiliza la alternativa indicada.

02

PRÁCTICA · TRES BÚSQUEDAS

Busca fuentes que respondan

  1. Abre Google: búsqueda avanzada ↗.
  2. En «todas estas palabras», escribe copias seguridad; en «sitio o dominio», escribe incibe.es; en «tipo de archivo», selecciona PDF. Pulsa Búsqueda avanzada.
  3. Abre un resultado de INCIBE. Comprueba el título, el host y el tipo de documento. No tenéis que elegir todos el mismo resultado.
  4. Repite la búsqueda con contraseñas y con malware, manteniendo el dominio y el filtro PDF.
  5. Completa los tres registros. Valora si cada título responde al término buscado y explica por qué, sin copiar párrafos.

Si aparece CAPTCHA o bloqueo, usa las fuentes de apoyo de cada registro. Si tampoco se abren, selecciona «No he podido consultar la fuente» y explica la limitación.

03

OBSERVACIÓN DEL NAVEGADOR

Qué dice la conexión

  1. Abre la web de INCIBE ↗. Pulsa Ctrl+L para ver la dirección completa.
  2. Chrome: pulsa el icono de controles o información a la izquierda de la dirección. Busca «La conexión es segura» o la información del sitio.
  3. Firefox: pulsa el candado o icono de información del sitio y consulta «Conexión» o «Más información», si aparece. Los nombres pueden variar.
  4. Lee lo que muestra el navegador sin cambiar permisos ni configuración. Si se ocultan los datos, escribe «no visible en este equipo» y utiliza la lectura de apoyo.

Si la web está bloqueada, basta con indicar el navegador, la situación y el motivo. Si has podido abrirla, anota también dirección y host.

Lectura de apoyo · HTTPS, certificados y navegación privada

El certificado ayuda al navegador a comprobar que la conexión corresponde al nombre del sitio visitado. Junto con HTTPS, protege los datos durante su transporte. Una web engañosa también puede tener un certificado válido: hay que revisar el host y contrastar lo que ofrece.

Si tu equipo no muestra estos datos, no puedes afirmar que has observado el certificado. Anota la limitación; esta lectura explica el concepto, pero no sustituye una observación real.

El modo privado reduce los rastros guardados por el navegador al terminar la sesión. No borra los archivos descargados ni los marcadores que hayas creado y no oculta la navegación a todos los sitios o a quien gestiona la red. Para esta práctica no necesitas abrirlo.
