TEORÍA ESENCIAL

El pasado de una página, con límites

Una versión archivada

Wayback Machine permite consultar algunas versiones de páginas guardadas en distintas fechas.

No conserva todo Internet ni todas las partes de cada web.

La fecha efectiva

Una consulta puede redirigir a otra captura. Anota la fecha que muestra la barra de la versión final que estás viendo.

No deduzcas la fecha solo del enlace ni del copyright.

Una afirmación conservada

El archivo puede conservar un texto, pero eso no demuestra por sí solo que su contenido sea verdadero.

Contrasta las afirmaciones importantes con otras fuentes primarias y fechas.

Ausencia no es inexistencia.

Si no encuentras capturas o una imagen no carga, registra ese límite. No concluyas que la página o la imagen nunca existieron.

En esta práctica solo consultamos capturas existentes.

No uses «Save Page Now», no envíes datos personales y no crees cuentas. Si hay un bloqueo, trabaja con las tarjetas. Describe el tema de las imágenes; no las descargues sin comprobar su licencia.

02

PRÁCTICA · NASA Y WAYBACK MACHINE

Observa, busca y compara

1. Observa la web actual

  1. Abre www.nasa.gov ↗.
  2. Localiza el título principal, el menú y una imagen visible. Anota el título o su tema, cómo se organiza el menú y el tema de la imagen.
  3. Si no abre, usa la versión «actual» del ejemplo H2 y señala esa fuente. Es un ejemplo ficticio.

2. Abre una primera captura

  1. Abre Wayback Machine ↗. Pega https://www.nasa.gov/ en la búsqueda del archivo y pulsa Enter o «Browse History». No pulses «Save Page Now».
  2. Elige un año, una fecha con captura en el calendario y una hora si aparece.
  3. Al abrir la página, mira la barra final del archivo. Si redirige a otra fecha, anota esa fecha efectiva. Copia la dirección final como referencia, sin usarla para adivinar la fecha.
  4. Si no se puede abrir o confirmar la fecha, indícalo. Puedes usar H1 y H2 para continuar.

Enlace orientativo del documento: intentar abrir el archivo de NASA ↗. Su fecha efectiva debe comprobarse al abrirlo.
